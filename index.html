Projects

    Flap Lab — Automata & formal languages

    A modern, browser-based alternative to JFLAP. Design and simulate finite-state machines, pushdown automata, Turing machines and transducers, backed by a TypeScript library for grammars, parsing and conversions.

  • Open source

    PrologEZ — Learn Prolog by running it

    An interactive, Jupyter-style course with 43 lessons and auto-checked exercises. Real SWI-Prolog 9 runs in your browser as WebAssembly, with a step-by-step interpreter that walks through resolution and unification.

    JavaScript · Vite · WebAssembly · Web Workers

    Live app ↗ (PrologEZ, opens in new tab) Source on GitHub ↗ (PrologEZ, opens in new tab)

  • Open source

    FumbleChess — A chess AI

    A transformer trained on real Lichess games predicts the move a human of a given rating would play, blunders included. A small AlphaZero-style tree search looks a few moves ahead, and you can watch it think live on the board.

    TypeScript · PyTorch · ONNX Runtime Web · WebAssembly
