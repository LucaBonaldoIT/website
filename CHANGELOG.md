# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Changed

- Migrated to Vite: source in `src/`, static files in `public/`, production build in the
  git-ignored `dist/` via `build.sh`.
- p5.js is now an npm dependency, lazy-loaded as its own chunk, instead of a vendored file.
- Scripts converted to ES modules; assets are fingerprinted by the build.

### Added

- New 1200×630 social card (`public/og-image.png`) in the site's paper-and-ink style, generated by
  `scripts/og-image.sh`; Open Graph image dimensions/alt and `twitter:image` meta tags.

- SEO: robots/OG/Twitter meta completed, JSON-LD `@graph` (WebSite, ProfilePage, Person, project
  list), richer web manifest, refreshed sitemap and a `404.html`.
- New "L" favicon set (SVG, ICO, PNG, apple-touch, Android) in the Flap Lab / PrologEZ style,
  generated by `scripts/icons.sh`.

### Removed

- Old `social.jpg` (replaced by `og-image.png`).
- Unused `globe.png` and `phone.png` images.
